# Formulário de cadastro hospitalar

Protótipo acadêmico de uma interface para cadastro de pacientes e informações de atendimento.

## Objetivo

Praticar formulários HTML, campos obrigatórios, seleção de opções e estilização com CSS.

## Tecnologias

- HTML5
- CSS3

## Como visualizar

Clone o repositório e abra o arquivo `index.html` no navegador.

> Projeto demonstrativo: não armazena dados e não deve ser utilizado com informações reais de pacientes.
